📌 About the Project

The CodeAlpha Calculator is a functional web-based calculator designed to perform basic mathematical operations through a clean and user-friendly interface.

This project was developed to strengthen my understanding of JavaScript logic, DOM manipulation, event handling, and responsive frontend design.

It combines a simple interface with practical functionality, allowing users to perform calculations using either mouse clicks or keyboard input.

✨ Features

- ➕ Addition
- ➖ Subtraction
- ✖️ Multiplication
- ➗ Division
- 🔢 Decimal number support
- ➕/➖ Positive and negative number conversion
- 💯 Percentage calculation
- ⌫ Delete the last entered digit
- 🧹 Clear all calculations
- ⌨️ Keyboard input support
- ⚠️ Division-by-zero error handling
- 📱 Responsive user interface

🚀 Getting Started

1. Clone the repository

git clone (https://github.com/nagireddyrakesh842-maker/CodeAlpha_calculator.git)

2. Open the project

Open the downloaded folder in Visual Studio Code.

3. Run the application

- Open "index.html".
- Right-click inside the editor.
- Select Open with Live Server.
- The calculator will open in your default browser.

⌨️ Keyboard Controls

Key| Function
0–9| Enter numbers
"+"| Addition
"-"| Subtraction
"*"| Multiplication
"/"| Division
"."| Decimal point
"Enter" or "="| Calculate result
"Backspace"| Delete last digit
"Escape" or "Delete"| Clear calculator
"%"| Percentage
