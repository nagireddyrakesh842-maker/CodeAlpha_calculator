# CodeAlpha Calculator

A responsive calculator built with HTML, CSS and JavaScript
as part of my frontend development internship.

## Features

- Addition, subtraction, multiplication and division
- Decimal number support
- Percentage conversion
- Positive/negative sign toggle
- Clear and delete controls
- Keyboard input support
- Division-by-zero error handling
- Responsive layout for mobile devices

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the repository.
2. Keep all three source files in the same folder.
3. Open index.html in a modern web browser.

## What I Learned

- Managing calculator state
- Handling user input and arithmetic
- CSS Grid and responsive design
- Testing edge cases and handling errors
